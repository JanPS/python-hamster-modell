Hamsterbau – Kurzreferenz

Ein schlanker Python-Interpreter im Browser, gebaut für das Hamster-Modell. Es steht ein bewusst kleiner Sprachumfang zur Verfügung – das reicht für alle Hamster-Aufgaben völlig aus.

Hamster-Befehle (Original)

vor()

Ein Feld vorwärts gehen.

linksUm()

90° nach links drehen.

nimm()

Ein Korn aufnehmen.

gib()

Ein Korn ablegen.

vornFrei()

True, wenn vorne frei ist.

kornDa()

True, wenn hier Korn liegt.

maulLeer()

True, wenn das Maul leer ist.

Zusatzbefehle (praktisch, nicht im Original)

rechtsUm()

90° nach rechts drehen.

kehrt()

Um 180° drehen.

Unterstützte Sprachelemente

Variablen & Zuweisung (= += -= *= /=), if / elif / else, while, for x in range(...), def name(...): / return, break, continue, pass, print(...), Vergleiche (== != < > <= >=), and / or / not, Rechenoperatoren (+ - * / // % **), Kommentare mit #, Zahlen, Text in Anführungszeichen, True/False/None.

Bewusst nicht enthalten

Listen, Dictionaries, Klassen, Imports, f-Strings, Slicing. Für den Hamster reicht das eingebaute Sprach-Subset völlig – das hält den Fokus auf Kontrollstrukturen statt auf Python-Vollständigkeit.

Bedienung

Territorium wählen oder unter „Territorium bauen“ selbst gestalten, Programm links eintippen, auf „Start“ drücken. Danach lässt sich der Ablauf Schritt für Schritt vor- und zurückspulen oder automatisch abspielen.
